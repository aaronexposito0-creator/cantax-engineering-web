CANTAX ENGINEERING — ORIGINAL STATIC WEBSITE V2

HOW TO OPEN
1. Extract the whole ZIP into a folder.
2. Double-click index.html to preview the fully offline site in a modern browser.
3. Open all navigation pages and the project brief wizard.

HOW TO PUBLISH FREE
Upload the contents of the extracted folder, with index.html at the root, to any static hosting provider that allows your intended commercial use. No Node.js, cloud database, API key, card or recurring server required.

REQUIRED BEFORE PUBLIC BUSINESS USE
1. Edit site-config.js and set CANTAX_CONTACT_EMAIL to the EXACT VERIFIED address of the project, in quotes. An unverified guessed address has deliberately not been included.
2. Verify final trade name and legal disclosures. Complete legal.html with actual legally required provider information and check professional requirements before commercial operation.
3. Check every service against your qualifications, insurance, available software licensing and the laws of your clients' jurisdictions.
4. Replace the illustrative CAD portfolio item with real owned and checked work when available. Do not upload old employers' proprietary designs.

FUNCTIONAL FEATURES
* 8 real HTML pages, responsive navigation with dropdown and mobile menu.
* Interactive CAD hero assembled/exploded view (illustration).
* Accessible service tabs, arrow-key controls, deep links.
* Portfolio filters.
* 4-step project enquiry wizard with form validation, review, copy-to-clipboard and downloadable TXT.
* Email client handoff after verified email configuration. No fake web-form sending.
* Accessibility including labelled fields, focus states, reduced-motion support.
* No third-party libraries, cookies, forms backend, external fonts or analytics.

CONTACT FORM NOTE
The website does NOT send an email from a server and does NOT collect files. Once configured, it opens the visitor's EMAIL CLIENT with prefilled content. This requires that the visitor has an email application configured. For inbox delivery without the email client you would need a genuine form service/backend (often with quotas/fees).

TECHNICAL LIMITS
Designed to be static and available on any static hosting. Provider uptime, future free-plan limits and browser/email client settings are beyond the page code.
